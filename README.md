# Sistema de atendimento público

Neste trabalho prático, o projeto Python é entregue ao aluno, sendo necessário preencher as soluções para cada uma das funcionalidades solicitadas pelo enunciado.

O projeto está estruturado da seguinte forma:

```bash
.
├── main.py
├── pytest.ini
├── README.md
├── requirements.txt
├── src
│   ├── attendance_system.py
│   ├── node.py
│   ├── person.py
│   ├── system_terminal_ui.py
│   ├── tad_double_linked_list.py
│   ├── tad_simple_list.py
│   └── utils.py
└── tests
    ├── conftest.py
    ├── test_attd_tad_double_link_list.py
    ├── test_attd_tad_link_list.py
    ├── test_data.py
    ├── test_grades.py
    ├── test_tad_double_link_list.py
    └── test_tad_link_list.py
```

Os ficheiros destacados a verde são os que necessitam de alterações para o desenvolvimento do projeto. Neste caso, os ficheiros attendance_system.py, tad_double_linked_list.py e tad_simple_list.py devem ser modificados. Os demais ficheiros dentro da pasta /src, incluindo main.py, devem ser analisados para auxiliar na compreensão do projeto. Se considerar fazer o exercício bónus considere alterar somente os ficheiros destacados a azul (node.py, person.py e system_terminal_ui.py)

Cada ficheiro contém indicações sobre se pode ser editado e, se sim, onde as alterações devem ser feitas.

Se o ficheiro puder ser editado, o cabeçalho do ficheiro está estruturado da seguinte forma:

```bash
# -----------------------------------------------------------------------------------

#                          NOTICE: RESTRICTED EDITING ZONE
#
#    You are only allowed to edit this file in the sections clearly marked for edits.
#      Any changes outside the allowed regions may be overwritten or cause errors.
#
#      Please follow the guidelines and only modify code where it explicitly says:
#
#                       >>> YOU MAY EDIT BELOW THIS LINE <<<
#
#            If you are unsure, consult your teacher or project supervisor.
#
# -----------------------------------------------------------------------------------
```

Indicação de onde editar no ficheiro:
```bash
# -------------------------------------------------------------------------------------
#                          >>> YOU MAY EDIT BELOW THIS LINE <<<        #--------------------------------------------------------------------------------------
```

Se o ficheiro não pode ser editado o cabeçalho do mesmo está da seguinte forma:
```bash
# -------------------------------------------------------------------------------

#
# This file is generated automatically or used as a reference by other systems.

```

Indicações de desenvolvimento

Antes de começar a desenvolver no projeto, devem ser instaladas as dependências listadas no arquivo requirements.txt utilizando o seguinte comando:

```bash
 >  pip install -r requirements.txt
```

Mais informações sobre como instalar dependências Python com um ficheiro visite https://ioflood.com/blog/pip-install-requirements-txt/

Para o desenvolvimento das soluções solicitadas em cada exercício, é fundamental analisar o projeto fornecido para entender os dados e as estruturas de dados que serão utilizadas.
Após o desenvolvimento das soluções para cada exercício, é necessário executar os testes para verificar se todas as soluções fornecidas estão corretas. No diretório do projeto, para executar os testes, basta executar o seguinte comando no Command Prompt:

```bash
 >  python -m pytest tests
```
